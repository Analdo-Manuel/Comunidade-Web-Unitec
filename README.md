# Comunidade-Web-Unitec
Criar uma ferramenta de apoio à decisão que utilize observações da Terra da NASA, juntamente com informações locais sobre o solo, características das culturas e prioridades dos agricultores, para ajudá-los a explorar estratégias de rotação que possam fortalecer a saúde do solo e adaptar suas propriedades às mudanças climáticas.
